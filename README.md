# ばってんLabo — New website

既存の `Web-Fukuoka/Batten.Labo` から独立した、新しいサービスサイトです。

## 内容

- 福岡のお店向けLINE公式アカウント構築・運用サポートの紹介
- サービス、業種別活用イメージ、料金、ご相談の流れ、FAQ
- 既存サイトのLINE相談先への導線
- プラン別の相談メッセージ作成・コピー
- スマートフォン対応、キーボード操作、動きを抑える設定への対応

## ファイル

`dist/` が公開対象です。ビルド不要のHTML・CSS・JavaScriptで構成しています。

```sh
node server.mjs
```

http://127.0.0.1:4173 を開いて確認できます。

## コンテンツについて

料金・サービス・相談先は2026-10-06時点の既存リポジトリ `Web-Fukuoka/Batten.Labo` の `service.html` を参照しています。写真とブランドアイコンも同リポジトリの素材を使用しています。業種別の紹介は活用イメージであり、導入実績ではありません。参考LPの他社実績・固有コピー・人物素材は使用していません。

## GitHub Pages

リポジトリ作成後、Settings → Pages → Source で GitHub Actions を選択すると、同梱ワークフローから `dist/` を配信できます。既存サイトの設定変更は不要です。

LINEのリンクを開いてもメッセージは自動送信されません。相談者が内容を確認して送信します。
